# Zefe Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. O orquestrador detalha os passos de cada tarefa (teste que falha → código → teste passa → commit) na hora de despachar; este plano fixa o que ele não pode decidir sozinho: arquivos, nomes, assinaturas, valores do design e o teste que prova cada tarefa.

**Goal:** Construir o Zefe, sucessor local do GDE: busca, páginas de disciplina/professor/sala, árvore de integralização, planejador com exportação `.ics` e o assistente Zefe (Bedrock, Amazon Nova) num painel lateral.

**Architecture:** Um único app Next.js (App Router) com Postgres. Scripts sincronizam caderno de horários e catálogo da DAC para o banco; páginas e assistente leem só do banco, pelas mesmas funções em `src/dados/`. Cálculos (conflito, integralização, previsão) são funções puras em `src/dominio/`, testadas sem rede. O Zefe é um laço de ferramentas sobre essas funções; toda alteração dele gera um registro que pode ser desfeito.

**Tech Stack:** Bun (pacotes, scripts, `bun test`) · Next.js + React + TypeScript · Tailwind + shadcn/ui e componentes das bibliotecas listadas no design · PostgreSQL 17 (docker-compose) + Drizzle · better-auth (plugin de código por e-mail) · AI SDK (`ai` + `@ai-sdk/amazon-bedrock`) · Zod · node-html-parser · Playwright (só para capturas de tela).

**Spec:** `docs/superpowers/specs/2026-11-16-zefe-design.md` — todo executor lê o design e este plano.

## Global Constraints

- Tudo em Next.js; autenticação com better-auth; textos da interface em pt-BR.
- **Nunca informação inventada:** horário, sala, vaga, crédito, pré-requisito e conflito vêm do banco e de `src/dominio/`. Previsão sempre com etiqueta "previsão". Regra de catálogo não entendida = texto original + "não verificado".
- Páginas nunca chamam a DAC; só os scripts de `scripts/sync.ts`. Coleta: no máximo 2 requisições simultâneas, User-Agent `zefe/0.1`, parser falha alto (`ErroParse`), nunca grava vazio em silêncio.
- Não copiar código de `github.com/guaycuru/gde` (GPL-3).
- Código reaproveitado vem de `~/Documents/projects/gedeé/src` (do próprio aluno). Não alterar a pasta `gedeé`.
- Só local: app em `http://127.0.0.1:4100`, Postgres em `127.0.0.1:5435` (5434 e 54322 já estão ocupadas nesta máquina). Nada de deploy.
- Bedrock: região `us-east-1`, modelo padrão `us.amazon.nova-2-lite-v1:0` (env `ZEFE_MODELO`), credenciais pela cadeia padrão da AWS (perfil `default` local). Nenhuma credencial no repositório.
- Zefe só responde para e-mails em `ZEFE_LIBERADOS` (lista separada por vírgula, em `.env.local`).
- Anos de ingresso aceitos: 2020 em diante. Fora da v1: avaliações, amigos, cardápio, mapa, calculadora de notas, pós-graduação, regras de fretado.
- Rodapé e `/sobre` dizem que o Zefe não é oficial da Unicamp nem da DAC.
- **Antes de usar a API de qualquer biblioteca (Next, better-auth, AI SDK, Drizzle, Tailwind, shadcn), conferir a documentação da versão instalada.** Não escrever de memória.
- Funciona em celular (390 px) e computador; claro e escuro; navegação por teclado e foco visível.
- Um commit por tarefa, mensagem em pt-BR no padrão `feat: …` / `fix: …`, terminando com `Co-Authored-By: Claude <noreply@anthropic.com>`.
- Atalho com limite conhecido leva comentário `// shortcut: <limite>, <quando melhorar>`.

## Review Focus

Cada linha tem um teste na tarefa dona do código (indicada entre parênteses).

1. **Turma sem horário ou com horário incompleto** adicionada à grade: aparece na lista com a marca "sem horário", soma créditos, não quebra a grade semanal, e `checarGrade` devolve `verificado: false` (T11).
2. **Semestre ainda não publicado (1S/2027):** planejador e Zefe mostram previsão rotulada com a evidência; disciplina sem histórico diz "sem histórico", não some nem inventa (T7, T12).
3. **Currículo com modalidades ou grupo de eletivas que o parser não entende:** a árvore renderiza, o grupo mostra o texto do catálogo e "não verificado", e os créditos dele não entram como cumpridos (T3, T9).
4. **Falha do Zefe** — Bedrock sem credencial, limitado (throttling) ou ferramenta com erro; usuário fora da lista de liberados: o painel mostra mensagem clara, o resto do site continua funcionando (T15).
5. **Código de disciplina digitado de qualquer jeito** (`si702`, `SI702A`, ` si 702 `) é normalizado; código inexistente leva a "não encontrei", nunca a erro 500 (T7, T8).
